Before sending

Include enough context to reproduce the issue without disclosing information that is not needed.

  1. App version and build number.
  2. macOS version and Mac model or architecture, when relevant.
  3. Exact steps, expected result, and actual result.
  4. The complete visible error text.
  5. Whether the issue also occurs in a new project.
Troubleshooting

Start with the safest checks.

Preserve the original project and source data while diagnosing. Duplicate important work before any large migration or cleaning operation.

A dataset will not import

Check the file extension, delimiter, encoding, quoting, JSON structure, file permissions, and available disk space. DataLabs supports CSV, TSV, JSON, JSONL, and Parquet. For a large supported file, try the DuckDB-backed path and preserve the source while diagnosing.

Python or R execution fails

Open the Environment workspace and verify the selected runtime, detected version, package inventory, and environment health. Confirm that the required package is installed for the same runtime DataLabs is using. Restart the kernel after environment changes.

A project or artifact appears missing

Confirm that the project folder still exists and that DataLabs has permission to access its location. Review Project Health and the project tree. Check Finder, Trash, external storage, cloud-sync status, source control, and your backups before creating replacement files.

The app is slow or a job appears stuck

Inspect the Jobs and Performance views, allow active work to finish when possible, and stop the current script or restart the kernel if necessary. Close unrelated heavy workloads and verify available memory and storage. Keep a copy of reproducible inputs before force-quitting.

How do diagnostics work?

Help ▸ DataLabs Diagnostics creates a local JSON file only at the location you choose. It may contain app/build and macOS versions, a hardware summary, detected Python information, project name and artifact counts, and recent log entries. Inspect and redact it before deciding whether to attach it. DataLabs never uploads the file automatically.

Where is DataLabs data stored?

Projects and application state are stored on your Mac. Use Settings ▸ Privacy ▸ Reveal Data Folder to locate application-support files. External projects, exports, Trash, Time Machine, cloud-backed folders, and Git remotes must be managed separately.

Protect your information

Share only what the case requires.

Do not send confidential datasets, credentials, private source code, access tokens, or proprietary model artifacts unless you have authority and the support case truly requires them. Redact file paths, names, and log messages as needed.

Privacy requests

For a privacy question or statutory rights request, use the subject “Privacy Request.” Do not include passwords, access tokens, full datasets, or unnecessary sensitive information.
